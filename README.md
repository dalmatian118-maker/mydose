# 🎬 브랜드 릴스 스튜디오 (초안)

학생이 쓴 **브랜드 스토리(텍스트)** 를 넣으면 **30초 이내 인스타그램 릴스(1080×1920 mp4)** 를 만들어 주는 도구입니다.
사진·영상·배경음악은 선택으로 추가할 수 있어요.

```
스토리 입력 → ① 대본(Claude) → [학생이 확인·수정] → ② 이미지 → ③ 목소리 → ④ 장면 영상 → ⑤ 자막 → ⑥ 합성 → 릴스 + 게시글 문구
```

## 실행 방법

```bash
npm install
cp .env.example .env      # API 키 입력
npm start                 # http://localhost:3000
```

- Node.js 22 이상이 필요해요. ffmpeg는 npm 패키지에 포함되어 있어서 따로 설치하지 않아도 돼요.
- 처음 실행할 때 자막용 한글 폰트(Noto Sans KR, Black Han Sans, OFL 라이선스)를 `assets/fonts/`에 자동으로 내려받아요.
- **API 키 없이 화면만 체험하기**: `DEMO_MODE=1 npm start` (예시 대본, 색상 카드 이미지, 무음 + 자막)

| 단계 | 사용하는 것 | 키가 없으면 |
|---|---|---|
| 대본 | Claude (`ANTHROPIC_API_KEY`) | 필수 (또는 `DEMO_MODE=1`) |
| 이미지 | OpenAI 이미지 생성 (`OPENAI_API_KEY`) | 색상 그라데이션 카드 |
| 목소리 | OpenAI TTS (`OPENAI_API_KEY`) | 무음 + 자막 |
| 영상 | ffmpeg 켄 번즈 효과 (확대·축소·이동) | 항상 동작 |
| 자막 | ffmpeg + libass (ASS 자막) | 항상 동작 |

학생이 직접 올린 사진·영상은 AI 이미지보다 우선해서 쓰여요. Claude가 사진을 직접 보고 어울리는 장면에 배치해요.

## 대본 작성 원칙 (`server/pipeline/playbook.js`)

수업 자료로도 쓸 수 있게 프롬프트를 한국어로 써 두었어요.

- **후킹 (0~3초)**: 질문형, 반전형, 고백형, 숫자형, 공감형, 궁금증형, 현장형 중에서 서로 다른 후보 3개를 만들고, 학생이 화면에서 고를 수 있어요. 인사나 브랜드 소개로 시작하지 않아요.
- **바이럴 구조**: 후킹 → 문제·계기 → 이야기·전환점 → 가치 → 마무리 순서예요. 2~4초마다 장면을 바꾸고, 중간에 '열린 고리'를 넣고, 마지막 장면을 첫 장면과 이어서 다시 보게 만들어요. 행동 유도(CTA)는 부드럽게 하나만 넣어요.
- **신뢰감·진정성**: 1인칭 구어체로 쓰고 스토리 속 구체적인 디테일을 살려요. 스토리에 없는 숫자·후기·효능은 지어내지 않고 과장 표현도 쓰지 않아요. 실패와 서툰 모습도 숨기지 않아요.
- **교육용 설명**: "왜 이렇게 구성했는지"와 "진정성 체크" 항목을 함께 보여줘요.

## 영상 규격

- 1080×1920, 30fps, H.264 + AAC, 30초 이내 (목소리가 길면 말 속도를 최대 25%까지 올려 맞춰요)
- 자막은 인스타그램 UI를 피해서 배치해요. 장면 키워드는 위쪽에, 내레이션 자막은 아래쪽에 들어가요(하단 버튼·캡션 영역 위). 첫 장면 키워드는 노란 박스로 크게 보여줘요.

## 폴더 구조

```
server/
  index.js              API 서버 (Express)
  pipeline/
    playbook.js         ★ 후킹·바이럴·진정성 지침 + 대본 JSON 스키마
    script.js           Claude로 대본 생성
    images.js           장면 이미지 (OpenAI / 임시 카드)
    voice.js            목소리 (OpenAI TTS / 무음)
    timing.js           장면 길이 계산, 30초 맞추기
    video.js            장면 클립 (켄 번즈 / 업로드 영상 자르기)
    subtitles.js        자막(ASS) 생성
    compose.js          최종 합성
    render.js           전체 순서 실행
public/                 학생용 웹 화면
test/                   단위 테스트 (npm test)
```
